# Build status — October 21, 2026

Resume Button 1.0.0 is complete as a local Windows-first application. Open http://127.0.0.1:4173 while its servers are running. Restart with `npm run local`, or build and use `npm run local:production`.

## Delivered

- Projects: create, search, edit, attach folders, and remove with confirmation. Removing every project stays empty after restart.
- Capture: guided/free notes, text imports, bounded folder scans, optional Git context, source selection/removal, and full browser draft recovery.
- Local inference: Qwen through llama.cpp; existing Ollama protocol support. Generation can be cancelled and retried with the draft intact.
- Evidence: exact source quotes and line links; author categories and next ideas take precedence; recaps derive from selected text; invalid selections are omitted.
- Resume: source inspection, immutable history, focus session, Markdown export, and card removal.
- Recovery: versioned JSON backup, preview, validation, and transactional restore as independent copies.
- Release: MIT license, third-party notices, production startup, Windows CI, contribution/setup/architecture docs, demo recordings, screenshots, and a local challenge article draft.

It uses a deterministic generator and an in-memory store; it does not claim to verify model quality.

The separate real-model flow checked cancelled generation saved no card, subsequent generation succeeded, latest author evidence and next idea were retained, source lines opened correctly, export downloaded, history reloaded, backups restored as copies, and successful drafts cleared. It reported zero page errors and zero remote browser requests. Generation took **92.078 seconds** for five sources on this machine. Earlier runs ranged from 2.9 seconds for small context to 49.6 seconds for larger context. These are inference measurements, not human time-savings results.

Screenshots were inspected at desktop and 390-pixel mobile widths. The source-linked card, capture form, and backup settings are usable. The short recording shows a saved real-model card; the full recording includes actual generation and cancellation.

## Limits

The small model can still omit or misclassify free prose. Guided labels are more reliable. Matching a quote does not verify interpretation, and cited AI suggestions can still be wrong. Generation uses one slot, a combined 180-second timeout, and one repair attempt; streaming is not implemented. CPU latency varies.

SQLite data, source copies, browser drafts, and JSON backups are plaintext. Backups omit browser drafts and folder attachments. Filename-based scan exclusions cannot identify every sensitive file. The bundled model setup targets Windows x64; other platforms require their own local runtime.

Actual human time saved remains unmeasured. On October 22, the source and recordings were published to [GitHub](https://github.com/AdityaAneNenu/resume-button) at the user's request. The DEV article is provided as Markdown; the challenge entry has not been submitted. Remaining submission steps are listed in `docs/RELEASE.md`.
