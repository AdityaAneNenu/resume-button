# Changelog

## 1.0.0 — October 21, 2026

First local release of Resume Button.

- Create, edit, search, and remove projects.
- Capture guided or free session notes, text imports, bounded folder scans, and Git context.
- Recover drafts with their sources and selections after closing or reloading.
- Generate cards with local Qwen through llama.cpp or an existing Ollama service.
- Retain exact evidence quotes, author categories, and recorded next ideas.
- Cancel generation without saving a partial card; retry with the preserved draft.
- Inspect cited source lines, browse history, start a focus session, and export Markdown.
- Download versioned backups and restore independent copies.
- Support desktop and mobile layouts with keyboard-accessible dialogs.
- Include checksum-verified model setup, production startup, isolated tests, Windows CI, documentation, and an MIT source release.

Small-model interpretation and CPU generation latency remain limitations. Sources, database files, drafts, and backups are not encrypted.
